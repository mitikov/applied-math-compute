### Початковий код

```python
import numpy as np
import matplotlib.pyplot as plt

G = np.array([
    [ 0, 40,  80, 120, 160],
    [20, 60, 100, 140, 180],
    [30, 70, 110, 150, 250]
], dtype=np.uint8)

def show_images(items):
    fig, axes = plt.subplots(1, len(items), figsize=(4 * len(items), 4))
    for ax, (data, title) in zip(np.atleast_1d(axes), items):
        if data.ndim == 2:
            ax.imshow(data, cmap="gray", vmin=0, vmax=255,
                      interpolation="nearest", origin="upper")
            # Числа допомагають відстежувати переміщення пікселів.
            for row in range(data.shape[0]):
                for col in range(data.shape[1]):
                    value = int(data[row, col])
                    ax.text(col, row, str(value), ha="center", va="center",
                            color="white" if value < 128 else "black")
        else:
            ax.imshow(data, interpolation="nearest", origin="upper")
        ax.set_xticks(range(data.shape[1]))
        ax.set_yticks(range(data.shape[0]))
        ax.set_xlabel("Стовпець")
        ax.set_ylabel("Рядок")
        ax.set_title(title)
    plt.tight_layout()
    plt.show()

def describe(name, data):
    # Для G кожне значення унікальне, тому координати однозначні.
    print(name, "| shape:", data.shape, "| dtype:", data.dtype,
          "| size:", data.size, "| nbytes:", data.nbytes)
    for value in [40, 250]:
        print("  Значення", value, "знаходиться в",
              np.argwhere(data == value).tolist())
    print("  Набір значень збережено:",
          np.array_equal(np.sort(data.ravel()), np.sort(G.ravel())))

show_images([(G, "Початкове зображення")])
describe("G", G)
```

Не змінюйте шкалу `vmin=0`, `vmax=255`, напрям `origin="upper"` та параметр `interpolation="nearest"`: вони забезпечують однакове відображення для порівнянь.

## Б. Транспонування та поворот на 90°

**Питання досліду:** чи є обмін рядків і стовпців поворотом зображення?

Для двовимірної матриці `T = G.T` виконується `T[col, row] = G[row, col]`. Піксель зберігає значення, але міняє місцями індекси.

3. Запустіть блок. Порівняйте транспонування з обома поворотами.
4. Визначте, яка додаткова дія перетворює транспоноване зображення на поворот.

```python
transposed = G.T.copy()

# Повороти побудовані з транспонування й зміни порядку однієї осі.
rotated_cw = G.T[:, ::-1].copy()
rotated_ccw = G.T[::-1, :].copy()

show_images([
    (G, "Початкове"),
    (transposed, "Транспонування"),
    (rotated_cw, "90° за годинниковою"),

      np.array_equal(restored_transpose, G))

      np.array_equal(transposed, rotated_cw))
```

### Що важливо розрізняти

У цих дослідах змінюються координати, а значення пікселів зберігаються. Рівність відсортованих значень перевіряє їхній набір разом із кількістю повторень, але не перевіряє розташування. Для повного порівняння масивів використовується `np.array_equal`.

Зрізи й транспонування NumPy можуть створювати представлення тих самих даних. У коді додано `.copy()`, щоб результати можна було надалі редагувати незалежно від оригіналу. `nbytes` описує обсяг елементів масиву; сума `nbytes` представлень не обов'язково є обсягом окремо виділеної пам'яті.

Тут досліджуються відображення та повороти, кратні 90°, які переставляють готові пікселі. Для довільного кута, наприклад 30°, зазвичай потрібне обчислення нових значень через інтерполяцію — це інша задача.
