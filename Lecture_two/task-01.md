# Практичні завдання до лекції 4

## Завдання 1. Наскільки точно ви зупиняєте таймер?

**Мета:** на власних даних обчислити абсолютну та відносну похибки окремого результату й побачити, навіщо потрібні обидві форми запису.

### Вимірювання

1. Відкрийте секундомір на телефоні. Запустіть його й спробуйте зупинити **рівно на 5,00 с**. Запишіть показ екрана.
2. Повторіть спробу **13 разів**. Записуйте всі результати в порядку отримання, навіть якщо якийсь дуже відрізняється від решти.
3. Проведіть ще **13 окремих спроб**, але тепер зупиняйте секундомір **рівно на 11,00 с**.
4. Перенесіть покази в Excel. Зберігайте ту кількість десяткових знаків, яку відображає телефон; не округлюйте числа перед обчисленнями.

Час 5,00 або 11,00 с є **заданим цільовим (опорним) значенням** для відповідної серії. Показ секундоміра у конкретній спробі позначимо `x`. Цей дослід оцінює, наскільки близько ви зупиняєте таймер до цілі; він не є калібруванням самого секундоміра.

### Таблиця й обчислення

Створіть в Excel таку таблицю: рядки **2–14** відповідають спробам **1–13**.

| Стовпець | Заголовок | Дані або формула для рядка 2 |
| --- | --- | --- |
| A | № спроби | `1` |
| B | Показ для цілі 5 с, с | Ваш перший показ |
| C | Абсолютна похибка для 5 с, с | `=B2-5` |
| D | Відносна похибка для 5 с, % | `=C2/5*100` |
| E | Показ для цілі 11 с, с | Ваш перший показ |
| F | Абсолютна похибка для 11 с, с | `=E2-11` |
| G | Відносна похибка для 11 с, % | `=F2/11*100` |

Заповніть номери від 1 до 13, внесіть усі 26 показів і протягніть формули зі стовпців C, D, F та G до рядка 14.

Формули відповідають означенням із лекції:

- **Абсолютна похибка:** `Δ = x − x_ref`, де `x` — показ секундоміра, а `x_ref` — ціль 5 або 11 с.
- **Відносна похибка:** `δ = (Δ / x_ref) × 100%`.

У цьому завданні **абсолютна похибка** `Δ` вимірюється в секундах, а **відносна похибка** `δ` — у відсотках. В обох випадках зберігайте знак: додатне число означає, що зупинили таймер пізніше цілі, від’ємне — раніше. Наприклад, показ 5,23 с дає `Δ = +0,23 с` і `δ = +4,6%`.

### Візуалізація

Побудуйте **два графіки точок** за номером спроби:

1. Для абсолютної похибки: по горизонталі № спроби, по вертикалі значення зі стовпців C та F (дві серії, одиниця — секунди).
2. Для відносної похибки: по горизонталі № спроби, по вертикалі значення зі стовпців D та G (дві серії, одиниця — відсотки).

Підпишіть серії «ціль 5 с» і «ціль 11 с». Нуль на вертикальній осі означає точне потрапляння в ціль; точки вище й нижче нуля показують запізнення та випередження. **Не поєднуйте секунди й відсотки на одній осі.**

Найпростіше побудувати ці графіки у [Excel для вебу](https://www.microsoft365.com/launch/excel) на основі вже заповненої таблиці. Якщо хочете показати графік окремо від таблиці, у [Desmos Graphing Calculator](https://www.desmos.com/calculator) можна вставити скопійовані з Excel пари стовпців «№ спроби — похибка» як таблицю; для другої серії додайте ще одну таблицю.

### Питання до результатів

- У якій серії абсолютні відхилення від цілі зазвичай більші? Чи змінюється висновок, коли порівнюєте відносні похибки?
- Чи бачите ви переважно додатні або переважно від’ємні похибки? Що це означає для ваших спроб?
- Чи помітна зміна від першої спроби до тринадцятої? Якщо так, що могло вплинути на результати?

**Що здати:** Excel-файл із 26 первинними показами, формулами та двома графіками, а також 3–5 речень із висновком. За бажанням додайте посилання або знімок графіка з Desmos. Не вилучайте «незручні» спроби з таблиці.
