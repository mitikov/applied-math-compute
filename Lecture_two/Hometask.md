## Part A. Lecture 2 — Python Challenges

### A1. Бюджет похибки кошторису

**Вхід:**
- список назв джерел похибки;
- список невід’ємних меж похибок у гривнях;
- допустима загальна межа.

**Базовий тест:** `40, 20, 1 грн`, допустима межа `30 грн`.

**Потрібно:**
- обчислити сумарну межу;
- знайти найбільшу складову та її назву;
- визначити, чи виконується допуск;
- обробити однакові максимальні значення.

**Перевірки:**
- від’ємна межа → некоректні дані;
- порожній список → некоректні дані;
- нульова складова допустима;
- сума, що точно дорівнює допуску, проходить перевірку;
- перестановка елементів не змінює бюджет.

**Пояснення:** чому сума є верхньою межею, а не обов’язково фактичною похибкою.

### A2. Перевірка вимірювання деталі

**Вхід:** еталон `x`, вимір `x_hat`, абсолютний допуск `T >= 0`.

**Набори:**
- `(100, 99, 0.5)`
- `(10, 9, 1)`
- `(0, 0.02, 0.05)`

**Потрібно:**
- `Δ = |x - x_hat|`;
- якщо `x != 0`, обчислити відносну похибку;
- якщо `x == 0`, повідомити «не визначена»;
- перевірити `Δ <= T`.

**Перевірки:**
- `Δ == T` вважається проходженням допуску;
- нульовий еталон не повинен спричиняти ділення на нуль;
- від’ємний ненульовий еталон має працювати через модуль знаменника.

### A3. Два способи округлення суми

**Вхід:**
```text
prices = [1.234, 1.234, 1.234]
digits = 2
```

**Потрібно:**
1. Округлити кожну позицію, потім знайти суму.
2. Спочатку знайти суму, потім округлити її.
3. Вивести обидва результати та різницю.
4. Окремо перевірити `round(2.5)` і `round(3.5)`.

**Пояснення:** порядок округлення, правило для точних половин, різниця між форматуванням і числовим округленням.

### A4. Межі площі прямокутника

**Вхід:**
- `a_hat > 0`
- `b_hat > 0`
- `0 <= Ea < a_hat`
- `0 <= Eb < b_hat`

**Тест:** `a_hat=2`, `b_hat=3`, `Ea=0.01`, `Eb=0.01`.

**Потрібно:**
- `S_hat`;
- `S_min`;
- `S_max`;
- лінеаризована оцінка першого порядку `L`;
- найбільше відхилення від `S_hat` до кінців інтервалу;
- порівняння цього відхилення з `L`.

**Перевірки:** нульові межі; лише одна ненульова межа; некоректні входи відхиляються до обчислення.

### B3. Завдання 2.3 — Базові операції над матрицями

**Джерело:** с. 40.

**Параметр:** `alpha = 0.01 * k`, де `k` — номер варіанта.

**Потрібно:**
- створити `A` форми `(4,4)` і `B` форми `(4,1)`;
- вивести `shape`;
- обчислити `det(A)`;
- знайти `A^-1`, якщо існує;
- перевірити `A @ A_inv` через залишок від одиничної матриці;
- знайти `A.T`;
- обчислити матричні `A^2` та `A^3`;
- для вибраного дійсного `x` обчислити `A + x` і `A * x`;
- дослідити `A + B`;
- обчислити `A @ B`;
- вручну перевірити хоча б один елемент `A @ B`.

**Обов’язково пояснити:**
- `A + x` — поелементне додавання;
- `A + B` для `(4,4)` і `(4,1)` — broadcasting, а не звичайна матрична сума;
- `A * B` — поелементне множення з broadcasting;
- `A @ B` — матричний добуток;
- `A**2` — поелементний квадрат, не матричний квадрат.
