У попередньому завданні кожен піксель задавався одним числом. У цьому кожен піксель містить **три значення в порядку R, G, B**: червона, зелена й синя складові. Усі значення — цілі числа від `0` до `255`.

Масив має форму `(висота, ширина, 3)`. Його можна розглядати як три матриці каналів, складені вздовж третьої осі. Індекси починаються з нуля:

- `image[row, col]` повертає три складові одного пікселя;
- `image[row, col, channel]` повертає одне число — значення вибраного каналу;
- `image[:, :, channel]` повертає матрицю цього каналу для всіх рядків і стовпців.

Порядок каналів у цьому завданні — саме **RGB**.

### Початковий код

```python
import numpy as np
import matplotlib.pyplot as plt

# У кожному пікселі числа записано в порядку [R, G, B].
image = np.array([
    [[255,   0,   0], [  0, 255,   0], [  0,   0, 255], [255, 255, 255]],
    [[255, 255,   0], [  0, 255, 255], [255,   0, 255], [  0,   0,   0]],
    [[ 40,  80, 200], [220, 160,  20], [128, 128, 128], [ 80, 120, 200]]
], dtype=np.uint8)

def show_images(items):
    fig, axes = plt.subplots(1, len(items), figsize=(4 * len(items), 3))
    axes = np.atleast_1d(axes)
    for ax, (data, title) in zip(axes, items):
        if data.ndim == 2:
            ax.imshow(data, cmap="gray", vmin=0, vmax=255,
                      interpolation="nearest", origin="upper")
        else:
            ax.imshow(data, interpolation="nearest", origin="upper")
        ax.set_xticks(range(data.shape[1]))
        ax.set_yticks(range(data.shape[0]))
        ax.set_xlabel("Стовпець")
        ax.set_ylabel("Рядок")
        ax.set_title(title)
    plt.tight_layout()
    plt.show()

# Змінюйте лише параметри нижче. Використовуйте цілі числа.
row = 2
col = 0
channel = 0  # 0 — R, 1 — G, 2 — B
value = 128

if not (0 <= row < image.shape[0] and 0 <= col < image.shape[1]):
    raise ValueError("Індекс пікселя виходить за межі зображення")
if channel not in (0, 1, 2):
    raise ValueError("Індекс каналу має бути 0, 1 або 2")
if not 0 <= value <= 255:
    raise ValueError("Значення каналу має бути від 0 до 255")

changed = image.copy()
changed[row, col, channel] = value

print("Форма:", image.shape)
print("Тип:", image.dtype)
print("Кількість пікселів:", image.shape[0] * image.shape[1])
print("Кількість числових елементів:", image.size)
print("RGB до зміни:", image[row, col])
print("RGB після зміни:", changed[row, col])

show_images([
    (image, "Початкове зображення"),
    (changed, "Змінено один канал")
])
```

Код відображення готовий. У першому експерименті змінюйте тільки `row`, `col`, `channel` і `value`. Початковий масив `image` залишайте незмінним.

Перестановка каналів змінює складові кольору, але не переставляє рядки, стовпці чи самі пікселі.

### Два способи перетворення на градації сірого

Для кожного пікселя порівняйте:

- просте середнє: `Y_mean = (R + G + B) / 3`;
- зважену суму: `Y_weighted = 0.299R + 0.587G + 0.114B`.

1. **До запуску** передбачте, чи однаковими будуть результати для чистих червоного, зеленого й синього пікселів у кожному зі способів.
2. Запустіть код і заповніть таблицю результатів.
3. Для двох із цих трьох пікселів обчисліть обидві формули вручну або калькулятором. Запишіть дробовий результат до округлення й зіставте з цілим значенням у масиві.
4. Перевірте сірий піксель `image[2, 2]`. Поясніть, чим цей випадок відрізняється від чистих основних кольорів.

```python
# Обчислюємо у float, щоб суми не переповнювали uint8.
work = image.astype(np.float64)

gray_mean_float = work.mean(axis=2)
weights = np.array([0.299, 0.587, 0.114])
gray_weighted_float = (work * weights).sum(axis=2)

# Обидва результати зберігаємо в одному типі для порівняння пам'яті.
gray_mean = np.clip(np.rint(gray_mean_float), 0, 255).astype(np.uint8)
gray_weighted = np.clip(np.rint(gray_weighted_float), 0, 255).astype(np.uint8)

show_images([
    (image, "RGB"),
    (gray_mean, "Середнє трьох каналів"),
    (gray_weighted, "Зважена сума")
])

for row, col in [(0, 0), (0, 1), (0, 2), (2, 2)]:
    print(
        f"Піксель ({row}, {col}): RGB={image[row, col]}, "
        f"середнє={gray_mean[row, col]}, "
        f"зважене={gray_weighted[row, col]}"
    )

for name, data in [
    ("RGB", image),
    ("Середнє", gray_mean),
    ("Зважене", gray_weighted)
]:
    print(
        name,
        "shape =", data.shape,
        "dtype =", data.dtype,
        "size =", data.size,
        "nbytes =", data.nbytes
    )
```

`axis=2` означає обчислення вздовж осі каналів: три значення одного пікселя перетворюються на одне. Рядки й стовпці зберігаються. Множення на `weights` застосовує ті самі три коефіцієнти до RGB-вектора кожного пікселя.

Зважена сума тут є навчальною моделлю перетворення кодових RGB-значень у сіре. Її не слід трактувати як універсальне фізичне вимірювання яскравості. Обидва результати округлюються та зберігаються як `uint8`.

| Піксель | Координати | RGB | Прогноз для середнього | Середнє, після округлення | Прогноз для зваженої суми | Зважена сума, після округлення |
| --- | --- | --- | --- | ---: | --- | ---: |
| Чистий червоний | `(0, 0)` | | | | | |
| Чистий зелений | `(0, 1)` | | | | | |
| Чистий синій | `(0, 2)` | | | | | |
| Сірий | `(2, 2)` | | | | | |

### Форма масивів і обсяг даних

Перенесіть результати останнього блоку коду в таблицю. Кількість пікселів обчислюйте як добуток висоти й ширини.

| Зображення | `shape` | `dtype` | Кількість пікселів | `size`: кількість числових елементів | `nbytes`, байтів |
| --- | --- | --- | ---: | ---: | ---: |
| RGB | | | | | |
| Сіре: просте середнє | | | | | |
| Сіре: зважена сума | | | | | |

У RGB-масиві `size` рахує всі значення каналів, а не лише пікселі. `nbytes` показує обсяг даних елементів масиву; він не включає службові дані Python-об’єкта та не є розміром PNG- чи JPEG-файла. Для порівняння використовуйте фінальні масиви `image`, `gray_mean`, `gray_weighted`: усі вони мають тип `uint8`. Проміжний масив `work` має інший тип і потребує більше пам’яті на одне число.
