### А. Дані власного варіанта — 5 хвилин

У клітинці наведено **навчальний приклад зі с. 87**. Спочатку запустіть його, потім замініть `A` і `b` даними власного варіанта 4.1 та повторіть запуск.

```python
A = np.array([[ 0.41,  1.00,  7.26, -1.00],
              [ 0.84,  2.65, -6.73,  0.80],
              [ 4.26, -1.55,  1.13, -0.44],
              [-0.45,  2.52,  1.54, -0.12]], dtype=float)
b = np.array([1.21, 1.44, 10.54, -2.67], dtype=float)

# Готова перевірка: десяткові коефіцієнти перетворюємо на точні дроби.
A_exact = sp.Matrix([[sp.Rational(str(v)) for v in row] for row in A])
det_exact = A_exact.det()
print("Розмір A:", A.shape, "; кількість правих частин:", len(b))
print("Точний визначник для введених коефіцієнтів:", det_exact)
print("Єдиний розв'язок:", det_exact != 0)
```

Для **квадратної** матриці `det(A) ≠ 0` гарантує єдиність розв'язку. Готовий службовий рядок із `Rational` обчислює визначник у точній арифметиці для введених десяткових чисел; писати його самостійно не потрібно. Він коректний для коефіцієнтів, безпосередньо введених із таблиці посібника, а не для попередньо округлених результатів інших обчислень. Коротке обґрунтування: «Визначник … не дорівнює нулю, тому розв'язок єдиний».

Якщо точний визначник нульовий, перевірте введення; обернену матрицю для такого `A` не обчислюють, а з одного лише нульового визначника не випливає відсутність розв'язків.

### Б. Два способи та інтерактивна зміна — 7 хвилин

```python
def solve_linear(first=float(b[0])):
    if det_exact == 0:
        print("Матриця вироджена: зупиніть дослід і перевірте дані.")
        return
    current_b = b.copy()
    current_b[0] = first
    by_inverse = np.linalg.inv(A) @ current_b
    by_solve = np.linalg.solve(A, current_b)
    print("Через обернену матрицю:", by_inverse)
    print("Через solve:", by_solve)
    print("Різниця методів:", np.max(np.abs(by_inverse - by_solve)))
    print("Нев'язка inv:", np.max(np.abs(A @ by_inverse - current_b)))
    print("Нев'язка solve:", np.max(np.abs(A @ by_solve - current_b)))

interact(solve_linear, first=FloatText(value=float(b[0]), description="Перша права"))
```

`np.linalg.inv(A)` знаходить обернену матрицю, `inv(A) @ b` реалізує формулу з посібника; `solve` розв'язує систему без явного створення оберненої матриці. `np.max(np.abs(...))` показує найбільший модуль серед компонентів.
