Рівень початковий: працюємо з готовими короткими заготовками й змінюємо лише дані, формули або початкові наближення. П'ять вправ послідовно готують до **обох завдань 4.1 і 4.2 власного варіанта**, а не змінюють нумерацію посібника.


**Сервіс:** [Desmos](https://www.desmos.com/calculator), кути в радіанах. Писати Python у цій роботі не потрібно.

### А. Рухома пряма — 5 хвилин

Уведіть у новій вкладці:

```text
x^2+y^2=5
c=-1
y=x+c
```

1. До запуску передбачте кількість спільних точок для `c=-1`.
2. Змінюйте `c` повзунком між `-4` та `4`; порівняйте `-1`, `0`, `4`.
3. Поверніть `c=-1`, наблизьте два перетини й запишіть їхні координати.
4. Для кожного перетину виберіть близьку пару, наприклад із координатами до одного знака після коми, яка буде стартом числового пошуку; точний перетин передавати не обов'язково.

| `c` | Кількість видимих перетинів | Приблизні координати |
|---|---|---|
| -1 | … | … |
| 0 | … | … |
| 4 | … | … |

Одне рівняння в системі може бути лінійним; наявність `x^2`, `y^2`, `sin(x*y)` чи інших нелінійних залежностей у решті вже робить систему нелінійною. Розв'язок має одночасно лежати на **обох** кривих.

### В. Межі висновку — 2 хвилини

Напишіть: «У вікні … видно … розв'язків». Скріншот скінченного вікна сам по собі не доводить їхню кількість на всій площині. Якщо виникає питання про додаткові віддалені перетини, позначте його для перевірки з викладачем; доведення збіжності числових методів тут не потрібне.

**Примітка посібника, с. 91:** якщо система має нескінченно багато розв'язків, потрібно знайти **чотири найближчі до `(0,0)`**; для порівняння відстаней можна використовувати `x^2+y^2`. Пошук чотирьох випадкових перетинів без перевірки близькості цю умову не виконує.
