### Б. Зміна правої частини — 6 хвилин

Скопіюйте готову клітинку:

```python
A = np.array([[1, 1],
              [2, 1]], dtype=float)

def change_total(total=7.0):
    b = np.array([5, total], dtype=float)
    answer = np.linalg.solve(A, b)
    print("[x, y] =", answer)
    print("Ліві частини A @ answer =", A @ answer)
    print("Праві частини b =", b)
    print("Нев'язки =", A @ answer - b)

interact(change_total, total=FloatText(value=7, description="Друга права"))
```

`np.array` перетворює вкладені списки на числову матрицю, `dtype=float` дозволяє дробові значення, `np.linalg.solve(A,b)` шукає вектор невідомих, а `@` виконує матричне множення. `FloatText` створює поле для експерименту: після введення нового числа результат перераховується.
