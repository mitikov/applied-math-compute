### А. Готова заготовка на навчальній системі — 4 хвилини

Для `x^2+y^2=5`, `y=x-1` нев'язки: `x^2+y^2-5` і `y-x+1`. Виконайте клітинку:

```python
def F(pair):
    x, y = pair
    return [x**2 + y**2 - 5, y - x + 1]

sx, sy = sp.symbols('x y')
expressions = [sx**2 + sy**2 - 5, sy - sx + 1]

def compare(x0=1.5, y0=0.5):
    start = [x0, y0]
    first, info, status, message = fsolve(F, start, full_output=True)
    print("fsolve [x,y]:", first, "; статус успіху:", status == 1)
    print("Нев'язки fsolve:", F(first))
    print(message)
    try:
        second = sp.nsolve(expressions, (sx, sy), start)
        print("nsolve [x,y]:", list(second))
        print("Нев'язки nsolve:",
              [value.subs({sx: second[0], sy: second[1]}).evalf()
               for value in expressions])
    except (ValueError, ZeroDivisionError) as error:
        print("nsolve не завершився:", error)

interact(compare,
         x0=FloatText(value=1.5, description="Старт x"),
         y0=FloatText(value=0.5, description="Старт y"))
```

Змініть старт спочатку на `[1.5,0.5]`, потім на `[-0.5,-1.5]`. Поля перераховуються після підтвердження вводу; під час зміни двох полів може з'явитися проміжний результат — до таблиці внесіть результат після встановлення **обох** координат. Перед запуском передбачте, до якого перетину приведе старт.

Готовий службовий код лише викликає методи й показує результати; інтерфейс і обробку помилок самостійно писати не потрібно. `F` повертає список нев'язок для SciPy, `expressions` містить ті самі вирази для SymPy, а `(sx,sy)` задає порядок невідомих. `nsolve` теж виконує числовий пошук, а не знаходить одразу всі розв'язки.
